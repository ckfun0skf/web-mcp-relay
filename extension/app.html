01 / DEPLOY

Your relay. Your quota.

Deploy to your own Cloudflare account. Never give this extension a Cloudflare API token.

  1. Sign in to Cloudflare and connect GitHub or GitLab.
  2. Clone a public repository via Git URL. If prompted for the source URL, enter:
    https://github.com/ckfun0skf/web-mcp-relay.git
    The deployment flow creates a copy in your own account; no local git clone command is required.
  3. Optional: make your new repository private if you prefer. If a visibility option is available during setup, select Private. Otherwise, after the copy is created on GitHub, open your repository → Settings → General → Danger Zone → Change repository visibility → Make private. Your account or organization must allow this change.

The source repository must remain public for the deployment button. Private visibility applies only to your own copy. Ensure the Cloudflare GitHub/GitLab integration retains access to that copy. A private repository does not make the deployed relay endpoint private or replace OWNER_SECRET.

Next, generate an OWNER_SECRET and enter it in the deployment settings. Closing the deployment popup does not confirm success. This guide stays open while you deploy.

02 / SECURE

Set your private secret

OWNER_SECRET authorizes relay connections. It is not a Cloudflare account API token.

  1. If the deployment wizard asks for OWNER_SECRET, enter the same secret there.
  2. Otherwise, after deployment go to Workers & Pages → your Worker → Settings → Variables and Secrets → Add.
  3. Select Secret, name it OWNER_SECRET, paste the value, then save and deploy.

The secret stays in this window's memory only. If you generate a new value, update Cloudflare to match.

05 / HANDOFF

Connect ChatGPT

  1. Add a custom MCP connection in ChatGPT using the /mcp URL below. Select None for authentication in this MVP.
  2. Verify that list_browser_tools and call_browser_tool appear in its tool list.
  3. Copy the temporary session key into your intended conversation and request list_browser_tools first.
  4. Each tool call opens this trusted window. Review the website and arguments, then select Allow once.

The session key is a secret capability. Share it only with a trusted client, never publicly. The old PoC pairing card is not used.
