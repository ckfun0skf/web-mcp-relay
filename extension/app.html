01 / PREPARE & DEPLOY

Prepare once. Then deploy.

Use this same value in Cloudflare. It is not a Cloudflare API token. It will be saved locally for the relay you connect to.

  1. Sign in and connect GitHub or GitLab. The source repository is included in the deployment link. If asked, use https://github.com/ckfun0skf/web-mcp-relay.git.
  2. Paste the copied secret into OWNER_SECRET when prompted. If not prompted, add it afterward under your Worker → Settings → Variables and Secrets as a Secret named OWNER_SECRET.
  3. Wait for Success! Build completed. in the deployment log.
  4. Copy the HTTPS URL directly below Deployed web-mcp-relay triggers, then return here and select Next.

Repository privacy and deployment help

Your new independent repository copy may be private if your account permits it. If setup has no visibility selector, change your GitHub copy under Settings → General → Danger Zone → Change repository visibility. Keep the Cloudflare integration authorized. The public source remains public. Private source visibility does not secure the deployed endpoint. For a full repository copy, use the repository root build settings.
