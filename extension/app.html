01 / DEPLOY

你的 relay，你的額度。

部署到自己的 Cloudflare。唔需要將 Cloudflare API token 交畀 extension。

  1. 登入 Cloudflare，連接 GitHub／GitLab。
  2. 確認建立自己的 repository 及 Worker。
  3. 下一步先產生 OWNER_SECRET，再貼到部署設定。

部署 popup 關閉不代表成功。此頁會保留，完成後可繼續。

02 / SECURE

設定私人金鑰

OWNER_SECRET 只授權 relay 連線，唔係 Cloudflare 帳戶 API token。

  1. 部署精靈如有 OWNER_SECRET 欄位，貼入同一金鑰。
  2. 否則部署後：Workers & Pages → 你的 Worker → Settings → Variables and Secrets → Add。
  3. Type 選 Secret，名稱 OWNER_SECRET，貼入金鑰並儲存／部署。

只保留在此視窗記憶體，唔會寫入設定檔。重新產生會使兩邊不一致，請同步更新。

03 / VERIFY

測試你的 relay

填 base URL，唔好加 /mcp。

URL 喺 Worker Overview 可以找到。健康檢查只確認服務版本，下一步先驗證金鑰及 WebSocket。

04 / CONNECT

連接已選定網站

讀取目標網站…

先確認網站已公開原生 WebMCP 工具；PoC 頁面需勾選允許執行。切換分頁唔會自動改變目標。

05 / HANDOFF

交畀 ChatGPT

  1. 在 ChatGPT 新增自訂 MCP 連接，貼入下方 /mcp URL。此 MVP authentication 選 None。
  2. 確認工具清單有 list_browser_tools 及 call_browser_tool。
  3. 複製短期 session key 到指定對話，先要求 list_browser_tools。
  4. 每次工具執行會開此可信視窗，確認網站、參數後按 Allow once。

Session key 是秘密能力憑證，只交畀你信任的 client；唔好公開分享。唔需要舊 PoC 配對卡片。
