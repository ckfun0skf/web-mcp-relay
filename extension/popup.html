Need to deploy a relay?
Use the same OWNER_SECRET in Cloudflare. Your prepared secret survives popup closure.
Deployment steps
  1. Sign in to Cloudflare and connect GitHub/GitLab. The source is preselected.
  2. Set OWNER_SECRET to the prepared value, or add it as a Worker Secret afterward.
  3. Wait for Success! Build completed.
  4. Copy the HTTPS URL below Deployed web-mcp-relay triggers. Use the actual name if renamed.
Source: https://github.com/ckfun0skf/web-mcp-relay.git. No Cloudflare API token is needed.
