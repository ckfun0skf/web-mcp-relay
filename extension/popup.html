Prepare your relay

Prepare the key before opening Cloudflare. Paste it into OWNER_SECRET when asked, or add it as a Worker Secret afterward. No Cloudflare API token is needed.

Deployment guide
  1. Sign in and connect GitHub/GitLab. The source repository is preselected.
  2. Configure the same OWNER_SECRET. An independent destination copy may be private if permitted; keep Cloudflare authorized.
  3. Wait for Success! Build completed.
  4. Copy the HTTPS URL immediately below Deployed web-mcp-relay triggers, using the actual Worker name if renamed.

If asked for the source: https://github.com/ckfun0skf/web-mcp-relay.git. Do not paste a dashboard/repository URL or append /mcp.

Reset and credentials

Credentials are stored locally per origin, not in an encrypted OS vault. Reset clears this extension's saved relay credentials and ends its session; Cloudflare resources are not deleted.

Allows ALL tools, including writes/deletes, without extension prompts. Refresh revokes trust, not the session key.

ChatGPT setup

Add the MCP URL as a custom connection with authentication None for this MVP. Use list_browser_tools with session_key, then call_browser_tool with its tool_id, snapshot and arguments. Client/browser approvals remain independent.
