Set up your AI agent connector

This guide describes this project's experimental remote MCP connection. Your AI client must support custom remote MCP servers; availability and menu names vary by client and account.

  1. Connect a WebMCP-enabled page using Connect Now. Wait until the private session panel reports Connected.
  2. In your AI agent's MCP server or connector settings, add the MCP server URL shown in the session panel. Use the HTTPS URL ending in /mcp, not the Cloudflare dashboard URL or bare Worker origin.
  3. For this MVP, choose authentication None if the client offers that setting. The browser connection uses OWNER_SECRET internally; the AI agent receives only session_key in tool arguments. None does not make the session key public or optional.
  4. Click Copy Session & Connector Details in the private session panel and paste the result into your trusted AI agent conversation. Copying a key does not itself install or configure a connector.
  5. Ask the agent to call list_browser_tools with session_key. It should then call call_browser_tool using the selected tool_id, the returned snapshot and the tool's arguments.
  6. Approve tool requests in the extension toolbar popup, or explicitly enable session trust there if appropriate. Client and browser approvals remain independent.

Session key versus owner secret

The session key is temporary access to the connected page. Treat it as a secret. OWNER_SECRET authenticates your browser to your relay and must never be pasted into the AI conversation or a website hint.

Troubleshooting

  • No tools detected: the browser API existing is not enough; the site must actually expose native WebMCP tools.
  • Disconnected: use the toolbar popup to inspect status and resume an unexpired session where possible.
  • Expired, ended or replaced session: connect again and share the new session key.
  • Page refreshed: list tools again to obtain a current document snapshot; trust is revoked on refresh.
  • Result unknown: do not automatically retry writes, deletes or submissions.
  • No custom remote MCP support: this connector cannot be used directly in that client.
