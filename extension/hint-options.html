WebMCP connection hints

Automatically show a compact hint on permitted sites when WebMCP is available. Previewing tools never executes them. Connecting does not enable session trust.

Website access

Automatic discovery needs optional website access. Start with one site; granting all sites is optional. Relay access alone does not authorize discovery on other websites.

Disabling hints stops discovery but does not remove host permissions used by relay connections. Manage or revoke site access in Chrome extension settings.

Relay credentials and session controls remain in the toolbar popup. These options do not reset relay setup.
