# Agent permissions (0.6.0)

Fix: checkbox handlers capture the user's new checked value before run() renders stored state. In-flight state reads cannot overwrite newer UI commands. The background, not a checkbox, enforces pause and authorization immediately before native dispatch. Pause rejects pending approval, revokes ephemeral grants, and blocks new calls; it cannot undo already-started website code. Resume is ask-each-time for the current document.

After a successful connection, an extension-owned dialog offers Ask Me Each Time, session trust, or persistent website trust. No choice means no tool execution. A previously always-trusted origin is applied without asking again; Agent permissions in the toolbar changes the current mode. Listing metadata remains read-only and does not require execution trust.

Manual approval has Allow Once, Always Allow This Tool on This Session, and Deny. Tool grants bind to the current session/document and exact registry metadata snapshot plus tool ID. Registry changes therefore require approval again. Reload revokes ephemeral session/tool grants; same-origin rebind retains the session key and reloads any saved website policy. Cross-origin navigation ends the session. Browser/worker restart does not restore ephemeral trust.

Persistent website trust is stored in TRUSTED_CONTEXTS local storage, keyed by exact origin including scheme and port. No subdomain wildcard, all-relay trust or agent-identity verification is implied: any client possessing the session key uses these permissions. All tools, including writes/deletes, are covered. The Options page lists trusted origins with Revoke. Revoking active-origin trust also invalidates in-flight permission decisions and future calls require approval. Selecting Ask in the dialog changes the current session mode only; use Options Revoke to remove a persistent grant. Reset relay setup does not erase website trust.

No secret credentials are sent to website UI. Existing background session/hint and copy-panel entry points remain compatible. No relay changes.
